Covered by `apps/backend/src/lib/__tests__/appledouble-quarantine.unit.spec.ts`.

## WebGL 3D scene determinism and candidate baselines

Root causes of the earlier `home-3d-studio.png` and `width-390` non-determinism were isolated strictly to the test harness:

1. Three.js `Clock` inside `@react-three/fiber` accumulated variable wall-clock network/disk transfer durations before pausing, shifting `Math.sin(elapsedTime * 0.7)` sway phase.
2. `@react-three/drei` `<Center>` evaluated its bounding-box offset after 1+ variable rotation frames, shifting world X/Z translation by ~`0.000048m`.
3. Playwright `clock.pauseAt` was not aligned to `16ms` `requestAnimationFrame` boundaries and could fail if real IPC latency exceeded `100ms`.
4. Overlay `pointer-events-auto` containers intercepted synthetic `page.mouse.move` over `<canvas>`, leaving residual `state.pointer` tilt.
5. Earlier `width-390` captures (`22:54:45`) were recorded before clock-pausing and top-scroll normalization (`scrollTo(0, 0)` after `hero-dot-0` click).

`apps/storefront/e2e/helpers/webgl-determinism.ts` resolves all five strictly inside test initialization (`addInitScript`) without modifying any production component or disabling production animations:

- Calibration (`playwright.calibration.config.ts`): **5/5 widths (`390, 768, 1024, 1440, 1920`) x 3 fresh browser contexts = 15/15 byte-for-byte identical PNG renders**.
- Candidate baselines (`apps/storefront/e2e/visual/candidate-baselines/`, `VISUAL_BASELINE_SET=candidate`, `maxDiffPixels: 0`, no canvas masking): **57 PNGs captured; 3 consecutive independent comparison runs passed 20/20, 20/20, and 20/20 (60/60 zero-diff comparisons)**.
- Default `playwright.visual.config.ts` continues pointing at untouched `baselines/` until the user approves promoting `candidate-baselines/`. Full SHA-256 and pixel comparison data is generated by `scripts/compare-visual-baselines.cjs`.
